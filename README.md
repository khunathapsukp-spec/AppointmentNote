ชื่อ : AppointmentNote เป็นโปรแกรมสำหรับการนัดหมายต่างๆ
เทคโนโลยีที่ใช่ : C# windows Forms, Visual Studio
วิธีดาว์โหลดหรือดึงโค้ดจาก gitHUb : กด Addfile และกดเปิดที่vsม่วง
วิธีเปิดโปรเจกต์และวิธีรันโปรแกรม : เมื่อเปิดขึ้นมาแล้วเข้าไปที่ solution Explorer คลิกไปที่ Form1.cs กดรันที่ แถบบนหน้าจอ
คำอธิบายหน้าจอ : รหัสนัดหมายไว้สำหรับใส่รหัสของการนัดหมาย หัวข้อการนัดหมายสำหรับเขียนหัวข้อของการนัดหมาย ความสำคัญใส่ความสำคัญว่าการนัดหมายสำคัญแค่ไหน สถานะสำหรับบอกสถานะว่าเสร็จหรือยัง
ตัวอย่างเพิ่มการนัดหมาย : เพิ่มรหัส เพิ่มหัวข้อ ใส่ความสำคัญและสถานะ เมื่อเสร็จแสดงสรุปผลว่ารหัสอะไร หัวข้ออะไร ความสำคัญระดับไหน สถานะเป็นยังไง
คำอธิบายปุ่ม clear,Exit : เมื่อกดclear จะล้างข้อมูลที่เคยใส่ไว้ เมื่อกดExitจะออกโปรแกรม
